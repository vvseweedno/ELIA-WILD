# Contribution policy

ELIA WILD is an owner-controlled research project. Unsolicited code,
configuration and documentation contributions are not accepted.

Only the repository owner may authorize changes to the canonical project.
Third-party contributions require a prior written invitation and a separate
contributor agreement covering ownership and licensing. Opening a pull request
does not grant the submitter or any other person rights to ELIA WILD.

Security reports should follow [`SECURITY.md`](SECURITY.md). General questions
and commercial-license requests may be directed to the repository owner through
[`github.com/vvseweedno`](https://github.com/vvseweedno).
